# ComfyUI 本地示例库设计与实现文档

## 🎯 项目背景
为RTX 4070 SUPER + i7-14700K + 62GB内存硬件平台定制的ComfyUI本地示例库，提供一站式的工作流示例、使用文档和批量测试能力。

## 📝 文档设计规范

### 单个示例文档结构
每个示例采用统一的Markdown文档结构：
1. **概述**：分类、功能、适用场景、运行时间
2. **原理说明**：通俗解释+工作流架构图
3. **硬件要求**：最低/推荐配置、当前硬件兼容性
4. **模型依赖**：下载地址、大小、是否必需
5. **使用方法**：界面操作+API调用两种方式
6. **效果展示**：输入输出示例对比图
7. **优化技巧**：针对RTX 4070 SUPER的专属优化
8. **常见问题**：常见错误和解决方案

## ⚡ 硬件适配体系

### 硬件检测模块能力
- 自动识别GPU型号、显存大小、CUDA版本
- 自动识别CPU型号、核心数、主频
- 自动识别系统内存大小、可用内存
- 自动评估硬件兼容性等级（高/中/低）

### 兼容性分类
- ✅ **兼容**：当前硬件可直接流畅运行
- ⚠️ **需优化**：需要调整参数或启用优化选项
- ❌ **不兼容**：硬件配置不足无法运行

### 硬件需求矩阵
| 示例类型 | 最低显存 | 推荐显存 | 最低内存 | 推荐内存 |
|---------|---------|---------|---------|---------|
| SD1.5 基础 | 4GB | 6GB | 8GB | 16GB |
| SDXL 基础 | 8GB | 12GB | 16GB | 32GB |
| FLUX 基础 | 12GB | 16GB | 32GB | 64GB |
| 视频生成 | 10GB | 16GB | 32GB | 64GB |
| 多模态 | 8GB | 12GB | 32GB | 64GB |

## 🔧 工具脚本设计

### 1. hardware_detector.py
- 功能：自动检测系统硬件配置
- 输出：硬件信息json文件、控制台打印信息
- 特点：跨平台支持Linux/Windows，自动适配不同硬件

### 2. batch_runner.py
- 功能：基于WebSocket API批量执行工作流
- 特性：
  - 支持按分类筛选运行
  - 自动收集运行时间、显存占用、错误信息
  - 自动保存输出图片到指定目录
  - 生成美观的HTML测试报告
  - 支持仅列出工作流不执行

### 3. 待实现脚本
- **workflow_validator.py**：检查工作流的模型依赖、配置正确性
- **generate_index.py**：自动扫描工作流和文档，更新INDEX.md
- **update_metadata.py**：自动更新元数据配置文件

## 🎨 交互设计

### 快速开始流程
1. 用户打开INDEX.md查看所有示例
2. 根据兼容性标记选择感兴趣的示例
3. 点击文档链接查看详细使用说明
4. 在ComfyUI中加载对应工作流运行
5. 或使用批量脚本自动运行所有兼容示例

### 批量测试流程
1. 启动ComfyUI服务
2. 运行`python scripts/batch_runner.py`
3. 脚本自动执行所有兼容示例
4. 生成包含所有运行结果和效果图的HTML报告
5. 用户可以查看报告了解每个示例的运行情况

## 💻 技术实现要点

### 核心技术栈
- Python 3.x 作为主要开发语言
- WebSocket API 与ComfyUI通信
- PyTorch 用于硬件检测和显存统计
- Markdown 文档体系
- JSON 元数据配置

### 兼容性考虑
- 完全不修改ComfyUI原有代码
- 所有文件都在local目录下，不影响现有功能
- 支持后续扩展更多示例和功能
- 适配不同硬件平台，自动调整兼容性判断

## 📊 性能优化方案

### RTX 4070 SUPER 专属优化
1. **FP8精度支持**：利用Ada Lovelace架构的FP8加速能力，降低显存占用30%
2. **注意力切片优化**：针对12GB显存优化，在不降低质量的前提下运行FLUX模型
3. **显存管理**：自动释放未使用的显存，支持同时加载多个模型
4. **参数预设**：为所有示例提供适配12GB显存的最优参数

### 运行效率优化
- 批量运行时复用已加载的模型，减少加载时间
- 支持多任务队列，自动调度工作流执行
- 异步执行，实时反馈运行进度
